## What it does

Initia provides infrastructure for application-specific rollups and a connected ecosystem. Its [official documentation](https://docs.initia.xyz/home/general/welcome) describes the Interwoven Stack, infrastructure choices, and tools for developers creating application environments.

The useful research distinction is between the underlying Initia network and each application-specific rollup. Shared infrastructure does not mean every application has identical governance, economics, or operational dependencies.

## The 2025 milestone

This listing records a **2025 mainnet launch**. An [Initia governance proposal dated April 26, 2025](https://forum.initia.xyz/t/mib-1-add-init-price-feed-to-connect/81) states that the mainnet and INIT token were already live a few days earlier.

The exact launch-day field is left blank because the cited governance record confirms the year and launch period, rather than independently establishing a precise calendar day. The date of a governance proposal should not be silently substituted for the network’s launch date.

## Network and token context

INIT is the network token identified in that launch-period governance record. Application-specific rollups can introduce additional assets and configuration choices. Evaluate the actual network and asset relevant to an application rather than relying only on the shared ecosystem name.

## What to research

- Identify the specific rollup, execution environment, and bridge used by the application.
- Review how upgrades, withdrawals, and infrastructure dependencies are handled.
- Separate incentive-program participation from evidence of lasting application demand.
- Read current technical documentation before applying launch-period assumptions to today’s network.
