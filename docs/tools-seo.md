# Tools and Crypto Quiz: search readiness

Implemented 19 October 2026 for `/tools`, all eleven `/tools/{slug}` pages and `/quiz`.

- Unique page titles, descriptions, focused H1 headings and existing absolute canonical/Open Graph/Twitter metadata.
- Server-rendered overviews, usage steps, three specific FAQs per page and related reading. Calculations still run locally and require no external API.
- Visible breadcrumbs and matching BreadcrumbList markup. WebApplication describes each free calculator; Quiz describes the knowledge test; CollectionPage and ItemList describe the directory. FAQPage markup repeats the exact visible FAQ text. No ratings or qualifications are invented. This markup does not promise rich results.
- Links from relevant published guides back to the tools or quiz, alongside related-tool navigation and the main menu. The quiz remains separate from the directory.
- Actual content update date in visible text, structured data and tool/quiz sitemap lastmod values. Update `ToolSeo::UPDATED_AT` when these pages change substantively; do not replace it with request time.
- Index/follow and large image preview allowed. Existing robots.txt allows public tools and quiz through the wildcard group while blocking private/editorial and utility routes. No special AI-only files or training-permission changes were needed.

Content is curated in `resources/data/tool-seo.json`; structured data is generated by `app/Support/ToolSeo.php`. JSON is escaped for embedding. `ToolSeoTest` checks all thirteen pages, metadata uniqueness, plain HTML answers, exact visible FAQ/schema matches, graph types, sitemap dates and article links. The existing calculator and browser tests check functionality and responsive navigation.

No paid reports or keyword-volume estimates were used in this implementation. Search Console indexing, current rankings, actual provider crawler visits and AI answer inclusion have not been measured or claimed. An HTTP check with a bot user-agent only demonstrates a response to that header, not access from the provider's crawler IP ranges. Search Console submission and ongoing performance tracking require access to the relevant property.

References checked:

- https://developers.google.com/search/docs/appearance/ai-features — ordinary search eligibility and useful textual content apply; no special AI markup is required, and indexing is not guaranteed.
- https://developers.google.com/search/docs/appearance/structured-data/sd-policies — structured data must reflect visible content.
- https://developers.openai.com/api/docs/bots — OAI-SearchBot governs ChatGPT search crawling separately from training permissions.
- https://schema.org/WebApplication and https://schema.org/Quiz — resource types.

No automated search-engine indexing or ranking guarantee is provided. Review discovery and queries in the site's verified Search Console property after recrawling.
