## What it does

Monad is an EVM-compatible Layer 1. Its [official technical introduction](https://docs.monad.xyz/) describes architectural work including parallel execution, asynchronous execution, and a dedicated database. The goal is to improve execution capacity while retaining compatibility with familiar Ethereum contracts and tooling.

## The 2025 milestone

Public mainnet launched on **November 24, 2025**, as recorded in Monad’s documentation. Uniswap’s [same-day integration announcement](https://blog.uniswap.org/monad-mainnet-is-now-live-on-uniswap) provides additional context from an application available at launch. This is a mainnet milestone, not the first announcement of Monad’s development.

## Network and token context

MON is the native network asset. The [mainnet network reference](https://docs.monad.xyz/developer-essentials/network-information) provides current connectivity and contract information, including wrapped MON. Mainnet and testnet are distinct environments even when wallet interfaces and developer tools look similar.

## What to research

- Compare the latest execution, gas, and compatibility documentation for your intended application.
- Distinguish published capacity claims from independently observed performance under a stated workload.
- Inspect validator participation and client requirements using current sources.
- Check the exact bridge, asset representation, and application contract involved in any cross-network activity.

A high-throughput design does not answer every question about an application’s reliability, liquidity, or economics. Keep network architecture, application behavior, and token valuation as separate parts of a research note.
